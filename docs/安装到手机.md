# 装到自己手机上（iPhone）

目标：把 GitHub Actions 产出的 `LibreTV-unsigned.ipa` 装进你的 iPhone，自己用。

---

## 先选路线

| 路线 | 你要有 | 装完能用多久 | 适合 |
|---|---|---|---|
| A. Sideloadly（推荐） | Windows 电脑 + 免费 Apple ID | 7 天，到期重签 | 大多数人 |
| B. 付费开发者账号 | 99 美元/年 | 1 年 | 不想每周折腾 |
| C. Mac + Xcode | 一台 Mac + 免费 Apple ID | 7 天 | 手边正好有 Mac |

三条路都**不需要越狱**，也都不会上架 App Store。

---

## 路线 A：Windows + Sideloadly

### 0. 前置检查

- iPhone 系统版本要 **iOS 15 或更高**。这个 App 的最低部署目标就是 15.0，低于 15 装不上。
- 电脑是 Windows 7 及以上。
- 你有一个 Apple ID（免费的就够，不需要开发者账号）。

### 1. 装依赖（这一步最容易翻车）

Sideloadly 官方要求 Windows 上安装 **网页版（非 Microsoft Store 版）的 iTunes 和 iCloud**。

如果你电脑上已经装了微软商店版的 iTunes，先去「设置 → 应用」把它卸载，再去 apple.com 下载网页版安装。商店版缺少 Sideloadly 需要的设备连接组件，装了也识别不到手机。

### 2. 拿到 .ipa

到 GitHub 仓库的 Actions 页面，跑一次 `Build unsigned iOS IPA`，完成后在该次运行页面底部下载 `LibreTV-unsigned-ipa`，解压得到 `LibreTV-unsigned.ipa`。

这个包是**未签名**的，本身装不上任何设备——它的用途就是交给 Sideloadly 用你的 Apple ID 重新签名。

### 3. 连接手机

用数据线把 iPhone 插到电脑。手机上会弹「要信任此电脑吗」，点**信任**并输入锁屏密码。

### 4. 用 Sideloadly 安装

1. 打开 Sideloadly，左上角确认已经识别到你的设备。
2. 把 `LibreTV-unsigned.ipa` 拖进窗口。
3. 在 `Apple ID` 栏填你的 Apple 账号。
4. 点 `Start`，输入密码。

如果你的 Apple ID 开了双重认证，Sideloadly 可能会要求你填**App 专用密码**，而不是账号密码。App 专用密码在 appleid.apple.com 的「登录与安全」里生成。

### 5. 在手机上信任签名

装完后直接点图标会提示「未受信任的开发者」。处理方式：

设置 → 通用 → VPN 与设备管理 → 在「开发者 App」下点你的 Apple ID → 信任。

### 6. 打开开发者模式（iOS 16 及以上必做）

苹果自 iOS 16 起要求：用个人证书签名的 App 必须开启开发者模式才能运行。这个开关默认关闭，而且**一开始可能根本不显示**。

- 如果「设置 → 隐私与安全性」里能看到「开发者模式」：打开它 → 重启 → 重启后解锁手机 → 弹窗点「打开」→ 输入锁屏密码。
- 如果看不到这一项：先把 App 装到手机上（第 4 步做完），菜单通常就会出现；仍然没有的话，检查系统是否低于 iOS 16。

## 路线 B：付费开发者账号

加入 Apple Developer Program（99 美元/年）后，签名有效期从 7 天变成 1 年，同时最多安装的 App 数量也不再限制在 3 个。

具体做法有两种：

1. 仍然用 Sideloadly，只是登录付费账号。
2. 在有 Mac 的前提下，用 Xcode 配置你的 Team 后 Archive 导出签名包，再上传 TestFlight 分发（TestFlight 可以给其他人装，但首次审核仍需走苹果流程）。

对这个 App 来说，如果你想长期稳定自用、又不想每周重签，路线 B 是唯一省心的选择。

---

## 路线 C：有 Mac 就用 Xcode

```bash
cd libretv-ios
npx cap open ios
```

Xcode 里选中 `App` target → Signing & Capabilities → 勾选 `Automatically manage signing` → Team 选你的个人账号 → 选你的 iPhone 作为运行目标 → 点运行。

免费账号同样只有 7 天有效期，到期重跑一次即可。

---

## 7 天到期了怎么办

免费签名到期后，App 打不开，提示需要重新验证。处理办法：

- **手动**：用同一个 Apple ID、同一个 Bundle ID 重新 Sideloadly 一遍，会覆盖安装，App 里的源列表和播放进度都保留（它们存在 App 的 localStorage 里，覆盖安装不清数据）。
- **自动**：Sideloadly 自带后台续签守护进程，可以每隔几天自动重签。代价是电脑要开机、并且和手机在同一网络。

## 常见卡点

**Sideloadly 看不到手机。** 先确认装的是网页版 iTunes 和 iCloud；然后在 iTunes 里能看到设备、手机上点了「信任」；再换一根数据线或换一个 USB 口试试。还不行就重启电脑和手机。

**提示 "Unable to Install" 或安装后闪退。** 检查 Bundle ID 是否和之前装的重复（重复就换一个），以及手机系统是否低于 iOS 15。

**一周内装太多次报错。** 免费账号有 App ID 配额限制，短时间内反复签名会撞上限，等几天或改用付费账号。

**App 能开但搜不到片。** 这不是安装问题，是源的问题。去 App 里右上角「源」页面，确认源是启用状态，接口地址能访问。接口失效是常态。
